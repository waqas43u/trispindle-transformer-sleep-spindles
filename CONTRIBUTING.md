# Contributing

This repository is a research-reproducibility package. Before opening an issue or pull request, please:

1. Confirm that no raw MASS-SS2/DREAMS data, expert annotations, participant identifiers, model checkpoints, or credentials are included.
2. State the dataset version, operating system, Python version, PyTorch build, and GPU/CPU environment used.
3. Do not alter frozen DREAMS evaluation outputs while claiming equivalence with the archived results.
4. Report numerical changes with the matching rule, annotation reference, aggregation level, and random seed.

For bug reports, include the smallest reproducible command and sanitized log excerpt. Contributions that change scientific defaults should document their rationale and should not overwrite the archived verified results.
